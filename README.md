# Hackathon Project

Shared workspace for a three-person hackathon project.

The problem statement, Aivar background, and relevant blog material will be added before application code is started.

## Collaboration

- `main` is the shared stable branch.
- Create focused branches from `main`, using names such as `feat/<short-description>`, `fix/<short-description>`, or `docs/<short-description>`.
- Open a pull request into `main` for shared work and get at least one teammate review before merging.
- Keep commits small and focused. Update this README as the project direction becomes concrete.
- Never commit credentials or local environment files. Use an ignored `.env` file for local secrets and commit only safe examples such as `.env.example` when needed.

## Context

Writing end-to-end tests can take significantly longer than building the feature itself. Although tools such as Playwright and Playwright agents can generate and execute browser tests, developers still need to provide context repeatedly and perform substantial manual setup and maintenance.

Aivar Innovations presents the challenge as an opportunity to automate this workflow. The team describes itself as a native services company and an AWS preferred partner, and asks participants to demonstrate an agent that can take an application from manual testing context to a working end-to-end test suite.

## Formulated Problem Statement

Given a web application URL, username, and password, build an AI-powered browser-testing agent that can independently explore the application, identify meaningful user workflows, generate a runnable Playwright-based end-to-end test suite, execute the tests, analyze failures, and heal the tests when the application or its selectors change.

The agent should minimize the amount of context that a developer must provide repeatedly. It should produce clear evidence of what it explored, which test cases it generated, how the tests ran, which tests failed, and how those tests were repaired.

## Required Capabilities

The solution should be able to:

1. Accept an application URL and valid login credentials.
2. Explore the application through a browser.
3. Discover important user workflows and convert them into test cases.
4. Write a working end-to-end test suite.
5. Run the generated tests and report their results.
6. Diagnose test failures.
7. Heal broken tests and rerun them successfully.

## Expected Demonstration

The demonstration should show the complete workflow:

1. Provide the agent with an application URL and credentials.
2. Let the agent explore the application.
3. Review the generated test cases and test files.
4. Run the end-to-end test suite.
5. Show how the agent responds to a broken test or application change.
6. Show the healed test running successfully.
